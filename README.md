# Methods Lab – Java Methods and Their Applications

**Programmer:** Cristina Marie B. Reyes  
**Course:** BS Computer Engineering  
**Language:** Java  
**File Name:** `MethodsLab.java`

## Description

This project demonstrates the use of Java methods and their applications. It includes mathematical operations, number checking, array processing, and recursive methods.

The program uses `Scanner` for user input and separates computations into reusable static methods. It also has an error handler too!

## Objectives

- Declare and call Java methods.
- Understand the difference between `void` and return-value methods.
- Pass arguments and return results.
- Perform mathematical operations using methods.
- Apply loops, arrays, conditional statements, and recursion.

## How to Run the Program

1. Clone or download this repository.
2. Open the project using a Java IDE (such as NetBeans, IntelliJ IDEA, or VS Code).
3. Open `MethodsLab.java`.
4. Compile and run the program.
5. Enter the requested values in the console.

You can also run it through the terminal:

```bash
javac MethodsLab.java
java MethodsLab
```
